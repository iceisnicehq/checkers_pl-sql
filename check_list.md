## 📐 Бизнес-правила (Раздел 5 README)

### Обязательное взятие
- [ ] Если есть взятие, ход без взятия запрещен
- [ ] Выбирается цепочка с максимальным числом снятых фигур
- [ ] При равенстве - любой из максимальных

### Траектории
- [ ] Простая ходит на 1 клетку вперед
- [ ] Простая бьет по диагонали на 2 клетки (или цепочкой)
- [ ] Простая бьет вперед и назад
- [ ] Дамка ходит на любое число клеток
- [ ] Дамка бьет с "пролетом" и произвольным приземлением

### Многократное взятие
- [ ] Повторный заход на ту же клетку допускается (если не приводит к повторному снятию)
- [ ] Повторное взятие одной и той же фигуры невозможно

### Превращение
- [ ] Немедленно в момент достижения последней горизонтали
- [ ] При возможности взятия - продолжение уже в статусе дамки

### Ничьи
- [ ] По N полуходов без взятий (настраивается)
- [ ] По повтору позиции заданное число раз (если включено)
- [ ] По соглашению сторон (явное завершение)

### Конкурентность
- [ ] Одновременные попытки хода не приводят к двойному ходу
- [ ] Принимается ровно один валидный ход в корректной очереди
- [ ] Консистентность статусов при параллельных запросах
