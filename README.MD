## Быстрый старт

### Настройка окружения

```sql
-- Включите вывод сообщений
SET SERVEROUTPUT ON SIZE UNLIMITED;

-- Посмотрите справку
BEGIN game_logic.info; END;
```

### Первая игра

```sql
-- 1. Создайте игру против ИИ (легкая сложность)
BEGIN game_logic.create_game(p_ai_difficulty => 'E'); END;

-- 2. Посмотрите доску
BEGIN game_logic.print_active_board; END;

-- 3. Сделайте ход
BEGIN game_logic.make_move('c3-d4'); END;

-- 4. ИИ автоматически ответит, и вы увидите обновленную доску
BEGIN game_logic.print_active_board; END;
```

## Работа с играми

### Создание игры (create_game)

Создает новую игру: PvP (против игрока), PvE (против ИИ) или Puzzle (задача).

**Параметры:**
- `p_opponent_username` - Имя оппонента для прямого вызова (необязателен, по умолчанию NULL). NULL = открытая игра.
- `p_ai_difficulty` - Сложность ИИ: 'E' (Easy), 'M' (Medium), 'H' (Hard) (необязателен, по умолчанию NULL = PvP).
- `p_player_color` - Ваш цвет: 'W' (Белые), 'B' (Черные) (необязателен, по умолчанию NULL = случайно).
- `p_rule_id` - Правила: 1 (Русские 8x8), 2 (Международные 10x10) (необязателен, по умолчанию 1).
- `p_time_limit_move_sec` - Лимит времени на ход в секундах (необязателен, по умолчанию NULL, диапазон: 30-300).
- `p_time_limit_game_sec` - Лимит времени на всю партию в секундах (необязателен, по умолчанию NULL, диапазон: 600-7200).
- `p_draw_moves_limit` - Лимит полуходов без взятий для ничьей (необязателен, по умолчанию NULL, диапазон: 5-20).
- `p_enable_pos_rep_draw` - Включить ничью по повтору позиции: 'Y'/'N' (необязателен, по умолчанию 'N').
- `p_puzzle_id` - ID задачи для решения (необязателен, по умолчанию NULL = обычная игра).
- `p_daily` - 'Y' если это задача дня (необязателен, по умолчанию 'N').

**Примеры:**
```sql
-- Игра против ИИ (Easy)
BEGIN game_logic.create_game(p_ai_difficulty => 'E'); END;

-- Решение задачи
BEGIN game_logic.create_game(p_puzzle_id => 10); END;

-- PvP игра с таймаутами
BEGIN game_logic.create_game(
    p_opponent_username => 'BOB',
    p_time_limit_move_sec => 60
); END;

-- Игра с ежедневной задачей
BEGIN game_logic.create_game(p_daily => 'Y'); END;
```

### Присоединение к игре (join_game)

Присоединяет вас к открытой игре или принимает прямой вызов.

**Параметры:**
- `p_game_id` - ID игры для присоединения (обязателен).

**Пример:**
```sql
BEGIN game_logic.join_game(p_game_id => 123); END;
```

### Выполнение хода (make_move)

Выполняет ход в текущей активной игре.

**Параметры:**
- `p_move_notation` - Нотация хода (обязателен).
  - Формат: 'a3-b4' для тихого хода
  - Формат: 'c3:e5' для взятия
  - Формат: 'c3:e5:g7' для многоходового взятия

**Примеры:**
```sql
-- Тихий ход
BEGIN game_logic.make_move('c3-d4'); END;

-- Взятие
BEGIN game_logic.make_move('c3:e5'); END;

-- Многоходовое взятие
BEGIN game_logic.make_move('h4:f6:d8:b6'); END;
```

### Просмотр доски (print_active_board)

Выводит текущее состояние доски активной игры.

**Параметры:**
- `p_game_id` - ID игры (необязателен, по умолчанию NULL = активная игра пользователя).
- `p_username` - Имя пользователя для поиска его активной игры (необязателен, по умолчанию NULL).
- `p_wait_for_turn` - 'Y' для ожидания хода/подключения, 'N' для немедленного вывода (необязателен, по умолчанию 'N').

**Примеры:**
```sql
-- Просмотр активной игры
BEGIN game_logic.print_active_board; END;

-- Ожидание вашего хода
BEGIN game_logic.print_active_board(p_wait_for_turn => 'Y'); END;

-- Просмотр игры другого игрока
BEGIN game_logic.print_active_board(p_username => 'ALICE'); END;
```

### Сдача в игре (resign_game)

Сдаться в текущей активной игре.

**Параметры:**
- `p_resign_match` - 'Y' для сдачи во всем матче, 'N' или NULL для сдачи только в текущей игре (необязателен, по умолчанию 'N').

**Примеры:**
```sql
-- Сдача в текущей игре
BEGIN game_logic.resign_game; END;

-- Сдача во всем матче
BEGIN game_logic.resign_game(p_resign_match => 'Y'); END;
```

### Отмена игры (cancel_game)

Отменяет открытую игру или вызов.

**Параметры:** Нет параметров.

**Пример:**
```sql
BEGIN game_logic.cancel_game; END;
```

### Предложение ничьей (draw)

Управление предложениями ничьей (только для PvP игр).

**Параметры:**
- `p_action` - Действие: 'O' (предложить), 'A' (принять), 'C' (отменить свое предложение) (обязателен).

**Примеры:**
```sql
-- Предложить ничью
BEGIN game_logic.draw('O'); END;

-- Принять ничью
BEGIN game_logic.draw('A'); END;

-- Отменить свое предложение
BEGIN game_logic.draw('C'); END;
```

### Просмотр реплеев (watch_game_replay)

Просматривает ходы завершенной игры пошагово.

**Параметры:**
- `p_game_id` - ID завершенной игры (обязателен).
- `p_moves_to_show` - Количество ходов для показа за один вызов (необязателен, по умолчанию 1).
- `p_restart` - Начать просмотр с начала ('Y') или продолжить ('N') (необязателен, по умолчанию 'N').

**Примеры:**
```sql
-- Просмотр первого хода
BEGIN game_logic.watch_game_replay(p_game_id => 77); END;

-- Просмотр следующих 5 ходов
BEGIN game_logic.watch_game_replay(p_game_id => 77, p_moves_to_show => 5); END;

-- Перезапуск просмотра с начала
BEGIN game_logic.watch_game_replay(p_game_id => 77, p_restart => 'Y'); END;
```

### Режим наблюдателя

**Просмотр активной игры (print_active_board)**

Для просмотра чужой активной игры используйте `print_active_board` с указанием `p_game_id` или `p_username`.

**Выход из режима просмотра (stop_spectating)**

**Параметры:** Нет параметров.

**Пример:**
```sql
BEGIN game_logic.stop_spectating; END;
```

## Работа с задачами

### Просмотр ежедневной задачи (show_daily_puzzle)

Показывает ежедневную задачу.

**Параметры:** Нет параметров.

**Пример:**
```sql
BEGIN game_logic.show_daily_puzzle; END;
```

### Просмотр списка задач (show_puzzles)

Показывает список доступных задач.

**Параметры:**
- `p_difficulty` - Фильтр по сложности: 'E' (Easy), 'M' (Medium), 'H' (Hard) (необязателен, по умолчанию NULL = все).
- `p_puzzle_id` - ID конкретной задачи для детального просмотра (необязателен, по умолчанию NULL = список всех).
- `p_solution` - 'Y' для показа решения (только для одной задачи по ID и только если были попытки) (необязателен, по умолчанию 'N').

**Примеры:**
```sql
-- Список всех задач
BEGIN game_logic.show_puzzles; END;

-- Задачи средней сложности
BEGIN game_logic.show_puzzles(p_difficulty => 'M'); END;

-- Детали задачи с решением
BEGIN game_logic.show_puzzles(p_puzzle_id => 1, p_solution => 'Y'); END;
```

### Просмотр своих задач (show_my_puzzles)

Показывает задачи, созданные вами.

**Параметры:**
- `p_difficulty` - Фильтр по сложности: 'E' (Easy), 'M' (Medium), 'H' (Hard) (необязателен, по умолчанию NULL = все).

**Примеры:**
```sql
-- Все свои задачи
BEGIN game_logic.show_my_puzzles; END;

-- Сложные задачи
BEGIN game_logic.show_my_puzzles(p_difficulty => 'H'); END;
```

### Создание задачи (create_puzzle)

Создает новую задачу из произвольной позиции.

**Параметры:**
- `p_board_position` - Позиция доски в формате CLOB (обязателен).
- `p_turn_to_move` - Чей ход: 'W' (Белые) или 'B' (Черные) (обязателен).
- `p_moves_to_solve` - Оптимальное количество ходов для решения (необязателен, по умолчанию NULL = игра с ИИ).
- `p_difficulty_level` - Сложность: 'E' (Easy), 'M' (Medium), 'H' (Hard) (необязателен, по умолчанию 'M').
- `p_solution` - Решение задачи в виде последовательности ходов (необязателен, по умолчанию NULL).

**Пример:**
```sql
BEGIN game_logic.create_puzzle(
    p_board_position => EMPTY_CLOB(),
    p_turn_to_move => 'W'
); END;
```

### Удаление задачи (delete_my_puzzle)

Удаляет задачу, созданную вами.

**Параметры:**
- `p_puzzle_id` - ID задачи для удаления (обязателен). Используйте 0 для удаления всех своих задач.

**Примеры:**
```sql
-- Удалить задачу
BEGIN game_logic.delete_my_puzzle(15); END;

-- Удалить все свои задачи
BEGIN game_logic.delete_my_puzzle(0); END;
```

## Работа с матчами

### Создание матча (create_match)

Создает матч (серию игр до N побед).

**Параметры:**
- `p_opponent_username` - Имя оппонента для прямого вызова (необязателен, по умолчанию NULL). NULL = открытый матч.
- `p_games_to_win` - Количество игр для победы в матче (необязателен, по умолчанию 3). Должно быть нечетным числом.
- `p_player_color` - Ваш цвет: 'W' (Белые), 'B' (Черные) (необязателен, по умолчанию NULL = случайно).
- `p_rule_id` - Правила: 1 (Русские 8x8), 2 (Международные 10x10) (необязателен, по умолчанию 1).
- `p_time_limit_move_sec` - Лимит времени на ход в секундах (необязателен, по умолчанию NULL, диапазон: 30-300).
- `p_time_limit_game_sec` - Лимит времени на всю партию в секундах (необязателен, по умолчанию NULL, диапазон: 600-7200).
- `p_draw_moves_limit` - Лимит полуходов без взятий для ничьей (необязателен, по умолчанию NULL, диапазон: 5-20).
- `p_enable_pos_rep_draw` - Включить ничью по повтору позиции: 'Y'/'N' (необязателен, по умолчанию 'N').

**Примеры:**
```sql
-- Матч с конкретным игроком
BEGIN game_logic.create_match(p_opponent_username => 'ALICE'); END;

-- Открытый матч
BEGIN game_logic.create_match; END;

-- Матч best of 5
BEGIN game_logic.create_match(
    p_opponent_username => 'BOB',
    p_games_to_win => 5,
    p_rule_id => 2
); END;
```

### Присоединение к матчу (join_match)

Присоединяется к матчу.

**Параметры:**
- `p_match_id` - ID матча для присоединения (обязателен).

**Пример:**
```sql
BEGIN game_logic.join_match(p_match_id => 555); END;
```

## Представления (Views)

### Представления без параметров

```sql
-- Открытые игры
SELECT * FROM v_open_games;

-- Активные игры (со статусом партии)
SELECT * FROM v_active_games;
SELECT * FROM v_active_games WHERE game_id = 123;  -- статус конкретной игры

-- Открытые матчи
SELECT * FROM v_open_matches;

-- Активные матчи
SELECT * FROM v_active_matches;

-- Правила игры
SELECT * FROM v_game_rules;
```

### Представления с фильтрами

```sql
-- Протокол партии (все ходы со статусом)
SELECT * FROM v_game_protocol WHERE game_id = 123 ORDER BY move_number;

-- Завершенные игры
SELECT * FROM v_ended_games;
SELECT * FROM v_ended_games WHERE rule_id = 1;  -- русские шашки
SELECT * FROM v_ended_games WHERE match_id IS NOT NULL;  -- игры из матчей

-- Завершенные матчи
SELECT * FROM v_ended_matches;
SELECT * FROM v_ended_matches WHERE rule_id = 1;  -- русские шашки

-- Детали матча (все игры в матче)
SELECT * FROM v_match_details WHERE match_id = 10 ORDER BY game_id;

-- История игрока (все партии всех игроков)
SELECT * FROM v_player_history;
SELECT * FROM v_player_history WHERE player_name = USER;  -- моя история
SELECT * FROM v_player_history WHERE rule_id = 1;  -- русские шашки
SELECT * FROM v_player_history 
WHERE start_time >= DATE '2025-01-01' 
  AND end_time <= DATE '2025-01-31';  -- за период
SELECT * FROM v_player_history WHERE match_id IS NOT NULL;  -- игры из матчей

-- Рейтинги/топ (все игроки, все сезоны)
SELECT * FROM v_player_ratings;
SELECT * FROM v_player_ratings WHERE season_id = 5;  -- конкретный сезон
SELECT * FROM v_player_ratings WHERE rule_id = 1;  -- русские шашки

-- Результаты Daily Puzzles (только для тех, кто решал)
SELECT * FROM v_daily_puzzle_results;
SELECT * FROM v_daily_puzzle_results WHERE player_name = USER;  -- мои результаты
```

## Правила игры

### Русские шашки (rule_id = 1, доска 8x8)

- Простая шашка: ходит на 1 клетку вперед по диагонали.
- Простая бьет: вперед и назад на 2 клетки (или цепочкой).
- Дамка: ходит на любое число клеток по диагонали.
- Дамка бьет: на любое расстояние с произвольным приземлением за бьющей.
- Взятие обязательно, но можно выбрать ЛЮБОЕ взятие.
- Превращение происходит немедленно при достижении последней горизонтали.

### Международные шашки (rule_id = 2, доска 10x10)

- Простая шашка: ходит на 1 клетку вперед по диагонали.
- Простая бьет: вперед и назад на 2 клетки (или цепочкой).
- Дамка: ходит на любое число клеток по диагонали.
- Дамка бьет: на любое расстояние с произвольным приземлением за бьющей.
- Взятие обязательно МАКСИМАЛЬНОЕ количество фигур.
- Превращение происходит при остановке на последней горизонтали.

### Общие правила

- Белые начинают первыми.
- Пат (нет ходов) = поражение.
- Отсутствие фигур = поражение.
- Ничья: по соглашению, по лимиту ходов без взятий, по повтору позиции.

## Система рейтингов

- Начальный рейтинг нового игрока: 500 для всех правил.
- Победа в обычной игре: +16 очков.
- Поражение в обычной игре: -16 очков.
- Решение задачи (первый раз): +5 очков.
- Решение ежедневной задачи: +5 очков (только один раз в день).
- Ничья: рейтинг не меняется.
- Минимальный рейтинг: 0 (не может быть отрицательным).
- Сезоны обновляются автоматически каждый месяц (scheduler).
- Формат сезона: "Месяц-Год" (например, "Январь-2025").
- При создании нового сезона триггер автоматически создает рейтинги для всех игроков по формуле: rating * 0.8 (минимум 500).
- Матч: +16 за победу в игре, -16 за поражение, +10*N бонус за матч (N = games_to_win).

## Триггеры и автоматические задания

### Триггеры

**trg_init_player_ratings** - Инициализация рейтингов при создании игрока
- Срабатывает после вставки новой записи в таблицу `players`.
- Автоматически создает записи рейтингов для нового игрока по всем правилам игры.
- Начальный рейтинг устанавливается в 500 очков для всех правил.

**trg_init_season_ratings** - Инициализация рейтингов при создании сезона
- Срабатывает после вставки новой записи в таблицу `seasons`.
- Автоматически создает записи рейтингов для всех существующих игроков в новом сезоне.
- Начальный рейтинг рассчитывается как `GREATEST(500, ROUND(старый_рейтинг * 0.8))`.

### Автоматические задания (Schedulers)

**DAILY_CHECKERS_PUZZLE_JOB** - Создание ежедневной задачи
- Запускается автоматически каждый день в 1:00.
- Проверяет наличие задачи на текущую дату.
- Если задача отсутствует, выбирает случайную общую задачу (приоритет задачам, не использовавшимся последние 30 дней).

**MONTHLY_SEASONS_JOB** - Создание нового сезона
- Запускается автоматически в первый день каждого месяца в 1:00.
- Проверяет наличие активного сезона на текущий месяц.
- Если сезон отсутствует, создает новый сезон с названием "Месяц-Год".

**INACTIVE_SESSIONS_TIMEOUT_JOB** - Закрытие неактивных сессий
- Запускается автоматически каждый час.
- Автоматически закрывает игровые сессии, которые неактивны более 24 часов.

## Ограничения системы

- Один пользователь может иметь только одну активную сессию.
- Активная сессия = игра (статус 'A', 'O', 'C') или просмотр (spectating).
- При попытке создать вторую игру будет ошибка.
- Длительное простаивание автоматически завершает сессию (scheduler, 24 часа).
- Лимит времени на ход: минимум 30 секунд, максимум 300 секунд (5 минут).
- Лимит времени на партию: минимум 600 секунд (10 минут), максимум 7200 секунд (120 минут).
- Лимит полуходов без взятий: минимум 5, максимум 20.

## Статусы игр

- 'O' - Open (Открытая, ждет соперника)
- 'C' - Challenged (Вызов, ждет принятия)
- 'A' - Active (Активная, идет игра)
- 'V' - Victory (Победа одного из игроков)
- 'D' - Draw (Ничья)
- 'T' - Timeout (Таймаут)
- 'R' - Resigned (Сдача)

---

## Формат нотации ходов

- Тихий ход: 'a3-b4' (откуда-куда)
- Взятие: 'c3:e5' (через двоеточие)
- Многоходовое взятие: 'h4:f6:d8:b6:f2' (через двоеточие)

## Примеры выводимой доски

### Доска 8x8 (начальная позиция)
```
  | A  B  C  D  E  F  G  H  |
--+--------------------------+--
 8| [b] [b] [b] [b]| 8
 7|[b] [b] [b] [b] | 7
 6| [b] [b] [b] [b]| 6
 5|[ ] [ ] [ ] [ ] | 5
 4| [ ] [ ] [ ] [ ]| 4
 3|[w] [w] [w] [w] | 3
 2| [w] [w] [w] [w]| 2
 1|[w] [w] [w] [w] | 1
--+--------------------------+--
  | A  B  C  D  E  F  G  H  |
```

### Доска 10x10 (начальная позиция)
```
  | A  B  C  D  E  F  G  H  I  J  |
--+----------------------------------+--
10| [b] [b] [b] [b] [b]| 10
 9|[b] [b] [b] [b] [b] | 9
 8| [b] [b] [b] [b] [b]| 8
 7|[b] [b] [b] [b] [b] | 7
 6|[ ] [ ] [ ] [ ] [ ] | 6
 5| [ ] [ ] [ ] [ ] [ ]| 5
 4|[w] [w] [w] [w] [w] | 4
 3| [w] [w] [w] [w] [w]| 3
 2|[w] [w] [w] [w] [w] | 2
 1| [w] [w] [w] [w] [w]| 1
--+----------------------------------+--
  | A  B  C  D  E  F  G  H  I  J  |
```

**Обозначения:**
- `[b]` - черная простая шашка
- `[B]` - черная дамка
- `[w]` - белая простая шашка
- `[W]` - белая дамка
- `[ ]` - пустая темная клетка
- `[.]` - подсвеченная клетка (возможный ход)
